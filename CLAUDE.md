# socimis — instrucciones para Claude Code

Las reglas de trabajo están en **`AGENTS.md`** (raíz) y mandan. Antes de escribir código, lee también `docs/PRD.md`,
`docs/ARCHITECTURE.md` y `docs/DESIGN_SYSTEM.md`: son la fuente de verdad del alcance, la arquitectura y la salida.
Antes de crear un lector, una fuente o un campo, mira si ya existe. No cambies la arquitectura ni añadas dependencias
si no hacen falta. Si los ficheros se contradicen o falta una decisión importante, pregunta a Juan por pantalla antes
de suponer.

Juan no es desarrollador: cuando algo requiera que él toque el Terminal, instrucciones exactas, un comando por línea y
qué se debe ver después. Las preguntas, en el selector de pantalla, con alternativas y lo que implica cada una.
Español, directo, frases cortas. Si algo no se sabe, se dice.
